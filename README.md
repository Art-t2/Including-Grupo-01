# Including-Grupo-01
Including es una solución digital orientada a mejorar la comunicación entre personas con discapacidad sensorial y del habla, y los distintos servicios de atención al público. La aplicación utiliza Inteligencia Artificial para realizar traducción bidireccional entre voz, texto y Lengua de Señas Peruana (LSP), permitiendo una interacción más accesible, autónoma e inclusiva.

El proyecto surge ante la necesidad de reducir las barreras de comunicación que enfrentan diariamente las personas con discapacidad auditiva, visual o del habla en entornos como centros de salud, bancos, municipalidades y otros servicios públicos o privados.

Objetivo

Facilitar la comunicación en tiempo real mediante tecnologías de accesibilidad que permitan a las personas con discapacidad desenvolverse de manera independiente, segura y eficiente en sus actividades cotidianas.
